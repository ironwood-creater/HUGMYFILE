# Manual test checklist (phone and computer)

Do this once on a computer (Chrome, Firefox or Edge, and Safari on a Mac if you have one) and once on your phone (Safari on iPhone and/or Chrome on Android). Use your own everyday files. For every tool, check: the file opens, the result downloads, the result opens in your normal apps, and there is no watermark.

## General

- [ ] Homepage: search "pdf", "50kb" and "wifi" finds the right tools.
- [ ] Menu: each tab (Image, PDF, QR Code, Signature, Image to Text) opens and links work; on the phone the ☰ menu opens and closes.
- [ ] Dark mode: the moon/sun button switches theme; reload keeps your choice.
- [ ] Drag and drop a file onto a drop box (computer), and paste a copied image with Ctrl+V / Cmd+V.
- [ ] After a result appears, try closing the tab without downloading: the browser asks before leaving.
- [ ] Turn on airplane mode after a tool page has loaded and its first run is done: running the tool again still works (proof nothing is uploaded).

## Image tools

- [ ] Compress Image: a phone photo gets smaller; try WebP and AVIF output; a PNG screenshot with "256 colors".
- [ ] Compress to 20 / 50 / 100 / 200 KB: each result shows a size under the limit.
- [ ] Bulk Image Compressor: 10+ photos, "Download all as ZIP" opens and contains every photo.
- [ ] Resize Image: exact pixels (lock on and off), percentage, and a preset (e.g. square post).
- [ ] PNG→JPG (transparent PNG becomes white), JPG→PNG, PNG→WebP, JPG→WebP, WebP→JPG, WebP→PNG, JPG→AVIF.
- [ ] A phone photo taken sideways/upright comes out the right way up in every tool.
- [ ] **HEIC to JPG on iPhone (Safari):** pick a HEIC photo from Photos → Convert → the JPG opens. (On iPhone, set Settings → Camera → Formats → *High Efficiency* first so new photos are HEIC.)
- [ ] **HEIC to JPG on Mac (Safari):** a `.heic` file converts.
- [ ] HEIC in Chrome/Firefox on Windows/Android: the friendly "Your browser can't open HEIC files…" message appears.
- [ ] Passport Photo Maker: 2×2 inch photo is 600×600 px and under 240 KB; 35×45 mm and 33×48 mm; custom sizes; printable 4×6 and A4 sheets print at the right size when printed at 100% / "actual size".

## PDF tools

- [ ] Merge: 3 PDFs, reorder by dragging and with arrows, result has all pages in order.
- [ ] Split: ranges (e.g. 1-2, 3-end), every page (ZIP), extract selected pages.
- [ ] Compress: Light keeps selectable text; Medium/Strong shrink a scanned PDF; a small text PDF shows "already compact" and offers the original.
- [ ] Rotate one page and all pages; Reorder pages; Delete pages.
- [ ] Add page numbers: each position and style, start number, skip first page.
- [ ] JPG to PDF: several photos, A4/Letter/Same as image, margins.
- [ ] PDF to JPG / PDF to PNG: 72/150/300 DPI, a single page and all pages (ZIP).
- [ ] Sign PDF: draw with finger (phone) and mouse (computer), type, upload a photo of your signature; drag, resize, add name and date; open the result in a PDF reader.
- [ ] Add Text to PDF: text with accents (é, ñ, ü, ç), image, box, circle, highlight, whiteout, undo; typing Arabic/Hindi/Urdu shows the "not supported yet" message.
- [ ] Fill PDF Form: a real government or bank form with fields; flatten option; a PDF without fields shows the friendly message.
- [ ] A password-protected PDF shows "This PDF is protected or damaged, so we can't open it."

## QR codes

- [ ] Each type (link, text, WiFi, WhatsApp, email, call, SMS, contact) scans correctly with your phone camera.
- [ ] WiFi code joins your network (try a password with ; or : in it).
- [ ] QR with your logo scans; colors and gradients look right; SVG opens in a browser/design app.

## Signature maker

- [ ] Draw with finger/mouse, undo, clear; type in each handwriting style; upload a photo of a signature on paper.
- [ ] Downloaded PNG has a transparent background (place it on a colored slide); SVG opens.

## Image to Text

- [ ] A photo of a printed page in English; a screenshot; a page in another language (choose it first).
- [ ] PDF to Text: a typed PDF (instant), a scanned PDF (OCR), copy and .txt download.
